Monte Carlo stock price simulation


This Python programme uses a Geometric Brownian Motion model to simulate possible AAPL stock price paths over a number of trading days.


Teh programme visualises the results in graph form and calculates helpful summary statistics for the terminal price distribution.


The implementation uses numpy for mathematical work, matplotlib for visualisation, pandas for handling data and yfinance for the real-world data.


In the analysis document, I explore how varying parameters changes the results of the simulation. I also consider assumptions and limitations of the model.
